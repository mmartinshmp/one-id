HMP GLOBAL ONE ID

Components and tokens

Everything on the sign-in and sign-up screens is built from the HMP Global design system plus one layer of brand theme tokens. Re-skinning for another brand means swapping the six theme tokens and the logo; nothing else changes.

Theme tokens

Set once per brand. Every brand-colored element reads these; nothing references a brand hex directly. Hover is not a token: it is color-mix(in oklab, var(--brand) 80%, black), so no per-brand value is needed. Tint is a 92% white mix for selected rows and highlights.

Input

System Input at a 46px height, 16px Elza, 6px radius, 16px side padding. Border Stone 400; focus switches the border to the brand and adds a 3px ring at 50% brand. Error switches the border to the error red and adds an icon-led message under the field. Disabled drops to 50% opacity.

Dropdown

Same box as Input with a trailing chevron. Combobox pattern: Arrow keys move, Enter selects, Escape closes, typing jumps. Lists over about 12 items get a search row (type-ahead filters as you type). Options are 44px rows; the selected row is semibold with a Stone 500 check; the highlighted row uses a Stone 100 fill. Dependent dropdowns are disabled with a placeholder naming what to pick first, and reset when their parent changes.

Checkbox, radio, progress

Checkbox

System Checkbox at 20px, 4px radius, brand fill when checked. Label row is 44px tall and clickable. Used for phone type (Home, Work, Mobile; any combination).

Radio

22px circle, 1.5px Stone 400 border; selected: 2px brand border with a 10px brand dot. 44px rows, two columns at desktop, one on mobile. Space or Enter selects.

Messages

Fix the 3 highlighted fields to continue.

Banner: shown above the form when two or more fields fail on submit, or when the server rejects the request. Focus moves to the first invalid field. Inline errors always accompany it; the banner never replaces them.

A new code was sent.

Status: success green with a check, announced politely. Resend then shows "Resend available in 30s" until the cooldown ends.

Accessibility checklist

Text contrast 4.5:1 or better on every surface; brand ink chosen per theme to pass. Visible 3px brand focus ring on inputs, dropdowns, buttons, links and radios. Every input and dropdown has a visible label tied with for/id or aria-labelledby. Helper and error text linked through aria-describedby; errors use role="alert". Dropdowns are combobox + listbox with full keyboard operation. Errors use an icon plus text, never color alone. Required marked with * and announced via the label. All controls and option rows are at least 44px tall. Reduced-motion users get no spinner or transition animation.
